# Design System & Aesthetics: Evo-Dash

This document outlines design tokens, color schemes, typography, and UI guidelines for the `evo-dash` management system.

---

## 1. Color Palette

- **Background (Deep Onyx)**: `#090a0f`
- **Card Surface**: `#11131f`
- **Inner Surface / Inputs**: `#0d0f1a`
- **Borders & Dividers**: `#1e2238`
- **Border Hover**: `#2a3050`
- **Brand Primary (Indigo)**: `#6366f1` / `#4f46e5`
- **Brand Secondary (Violet / Purple)**: `#8b5cf6` / `#a855f7`
- **Success / Completed**: `#10b981` (Emerald)
- **Warning / Reg Closed**: `#f43f5e` (Rose)

---

## 2. Typography

- **Headings**: Sans-serif, bold tracking-tight
- **Body**: Slate-100 / Slate-300
- **Meta / Labels**: Slate-400, Slate-500
- **Monospace Tokens**: Slugs, IDs, order indices (`font-mono`)

---

## 3. Component Standards

- **Modals & Overlays**: Backdrop-blur (`backdrop-blur-sm`), semi-transparent black overlay (`bg-black/80`).
- **Cards**: Border-radius 12px-16px (`rounded-xl` / `rounded-2xl`), subtle border hover transitions.
- **Buttons**: Rounded-xl (12px), primary buttons with indigo glow shadow (`shadow-indigo-600/20`).
- **Previews**: Live card preview replicating the Evolvia frontend card styling.
